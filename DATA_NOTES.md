# Data minimization

The supplied Listings.csv was 159 MB. Only Paris rows and the five fields used by this notebook are included: host_since, neighbourhood, city, accommodates and price. Host/listing IDs, listing names, host locations and exact coordinates are excluded. This is a minimized derivative, not the original full dataset.

The analysis is observational. A post-2015 pattern does not prove regulation caused price or host-entry changes. Data redistribution rights remain unverified; the data file is included in this repository at the owner's request, and no license is assigned to it.
